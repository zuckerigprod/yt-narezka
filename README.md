# yt-narezka

Качает видео с YouTube и режет его на куски по таймкодам. Работает на Windows и macOS, ставить ничего не надо: скачал, запустил.

Делал для себя, когда надоело каждый раз качать ролик целиком и потом резать его руками в ffmpeg.

## Как пользоваться

Вставляете ссылку, жмёте «Загрузить информацию», задаёте отрезки и папку, потом «Скачать и нарезать». Файлы называются по названию видео: `Название - 01.mp4`, `Название - 02 - Вступление.mp4` (если у отрезка есть название).

Отрезки можно задать несколькими способами:

- руками, время пишется как `83`, `1:23` или `1:02:03.5`, а пустой конец значит «до конца видео»;
- шаблоном: куски по 5, 10, 15, 20, 30 секунд, по минуте, по 5 минут или своей длины, на всё видео или только на кусок «с ... по ...»;
- списком, например скопировать таймкоды из описания ролика. Понимает и `0:10-0:45 Название`, и просто `12:30 Глава`, тогда конец берётся из следующей строки;
- если у видео есть главы, они подставляются одной кнопкой.

Качество можно выбрать от 480p до максимального, либо выгрузить только звук в mp3.

Режим нарезки по умолчанию точный: видео перекодируется и режется ровно по кадру, но это медленнее. Есть быстрый режим без перекодирования. Он почти мгновенный, но режет по ключевым кадрам, так что начало куска может уехать на секунду-две.

## Первый запуск

Сама программа весит около 17 МБ. При первом запуске она докачивает yt-dlp, ffmpeg и deno (вместе примерно 150 МБ) и складывает их сюда:

- Windows: `%APPDATA%\YT Narezki\data\bin`
- macOS: `~/Library/Application Support/YT Narezki/bin`

yt-dlp обновляется сам раз в сутки. YouTube регулярно что-то меняет, и старые версии перестают качать.

На macOS сборка не подписана сертификатом Apple, поэтому в первый раз открывайте её через правый клик и «Открыть». Если система пишет, что приложение повреждено:

```
xattr -cr "/Applications/YT Narezki.app"
```

Windows может показать синее окно SmartScreen. Там нужно нажать «Подробнее», потом «Выполнить в любом случае».

## Скачать

Готовые сборки лежат в [Releases](../../releases): exe для Windows и `.app` для macOS (один файл и для Apple Silicon, и для Intel).

## Сборка из исходников

Нужен Rust.

```
cargo build --release
```

Сборки под обе системы собирает GitHub Actions, см. `.github/workflows/build.yml`. Когда пушится тег `v*`, файлы сами выкладываются в Releases.

Внутри всё на Rust и egui, скачивание через [yt-dlp](https://github.com/yt-dlp/yt-dlp), нарезка через [ffmpeg](https://ffmpeg.org).
